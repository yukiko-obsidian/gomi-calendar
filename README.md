# ごみ収集カレンダー（iPhone ホーム画面アプリ）

所沢市 北野南・小手指南地区のごみ収集カレンダーを、iPhone のホーム画面から
アプリとして開けるようにしたものです（PWA 方式）。デザインは元の Web 版のままです。

## iPhone への入れ方

1. iPhone の **Safari** で公開 URL を開く（Chrome ではホーム画面追加が正しく動きません）
2. 画面下の **共有ボタン**（□に↑）をタップ
3. **「ホーム画面に追加」** をタップ
4. 名前が「ごみカレンダー」になっているのを確認して **「追加」**

これでホーム画面にアイコンが並びます。タップすると Safari の枠が出ない
全画面のアプリとして開きます。

## 特長

- **オフラインで開ける** … 一度開いておけば、機内モードや圏外でも表示されます
- **日付の自動更新** … アプリを閉じずに日付が変わっても「TODAY」が自動で切り替わります
- **検索避け済み** … `noindex` 指定により検索エンジンには載りません
  （同梱の `robots.txt` は保険です。robots.txt はドメイン直下にしか効力がないため、
  実際に効いているのは `index.html` 内の `<meta name="robots" content="noindex, nofollow">` の方です）

## 公開範囲について

無料ホスティングの都合上、**URL を知っている人は誰でも閲覧できます**（完全非公開にはできません）。
載っている情報は「所沢市 北野南・小手指南地区」という地区名と市の代表電話番号だけで、
どちらも所沢市が公開している情報です。氏名・番地などは含まれていません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（元の Web 版 + iPhone アプリ化の設定） |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | オフライン用（Service Worker） |
| `icons/` | ホーム画面アイコン |
| `robots.txt` | 検索エンジン除け |

## 中身を更新したいとき

`index.html` を書き換えたあと、**`sw.js` の 3 行目の `v1` を `v2`, `v3`… と
1 つ増やしてください**。これをしないと、iPhone 側に古い内容がキャッシュされたままになります。

更新後、ホーム画面のアプリを一度閉じて開き直すと新しい内容になります。

## 手元で確認したいとき（Mac）

このフォルダで次を実行し、ブラウザで http://localhost:8765 を開きます。

    python3 -m http.server 8765

（`file://` で直接開くとオフライン機能が動かないため、必ずサーバー経由で確認してください）
